# promptsbaba logo quick guide

## Approved mark
The seated sage icon uses a deep espresso silhouette with a saffron-orange center. The mark is supplied as a transparent PNG master and high-resolution raster exports.

## Colors
- Espresso: `#38251C`
- Saffron orange: `#E87516`
- App background: `#24150F`
- White: `#FFFFFF`

## Use
- Use the full-color mark on white, cream, or a calm dark background.
- Use the espresso version on light backgrounds and the white version on dark backgrounds.
- Keep proportions locked; do not crop, stretch, rotate, or add effects.
- For browser and app icons, use the square icon exports. The favicon files are ready for direct use.

## Files
- `promptsbaba-symbol-color@3x.png`: high-resolution transparent master
- `promptsbaba-symbol-color.png`: approved color mark, transparent
- `promptsbaba-symbol-espresso.png`, `promptsbaba-symbol-black.png`, `promptsbaba-symbol-white.png`, `promptsbaba-symbol-saffron.png`: monochrome variants
- `promptsbaba-icon-transparent-512.png`, `promptsbaba-icon-white-512.png`, `promptsbaba-app-icon-512.png`: square icon contexts
- `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png`: browser icons
- `icon-192.png`, `icon-512.png`, `maskable-512.png`, `site.webmanifest`: PWA icon set

The production master is raster-based; a clean vector redraw can be supplied separately if needed for print or very large-scale use.
