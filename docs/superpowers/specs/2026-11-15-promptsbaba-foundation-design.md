# PromptsBaba foundation

The user approved proceeding step by step with the recommended static-library fork. This is stage 1: a complete local brand and ownership foundation, preserving imported content and source credit.

## Direction

Keep Astro, Tailwind, static JSON and the existing read-only MCP protocol. A rewrite adds no value at this stage. Rebrand to PromptsBaba at https://promptsbaba.com. Apply the supplied obsidian (#0B0F17), surface (#131A26), border (#1E293B), saffron (#F59E0B), emerald (#10B981), text (#F8FAFC) and muted (#94A3B8) palette. Default to dark, with a persistent light toggle. Use Plus Jakarta Sans headings and Geist/Geist Mono text. A new typographic PB mark replaces the upstream logo.

## Scope

Centralize site identity; update metadata, canonical URLs, browser chrome, hero and MCP identity. Remove upstream telemetry and donation destinations from the served product. Do not invent repository ownership or contact details: leave optional destinations disabled until supplied. Preserve LICENSE and explicit upstream acknowledgement, all prompt text and third-party licenses. Use actual catalog counts, collection-based credit when individual authors are unknown, and no unsupported testing claims.

## Approach and constraints

Chosen approach: incrementally adapt the existing static site, as recommended and approved in chat. A framework rewrite and a full account-based application were rejected as unnecessary for this milestone. Keep existing prompt URLs. Existing /mcp remains the library connector during stage 1. MCP directory, unified search, guides, and saved prompts are subsequent milestones. No fake MCP count, empty navigation destinations, new dependencies, commits, pushes or deployment.

## Validation

Existing data/MCP tests and full build; regression coverage for unconfigured telemetry; inspect generated metadata and links; exercise home, theme, search and copy in a real browser at desktop and mobile sizes. Run graphify update after edits.

The user supplied https://github.com/heysamai/promptsbaba during implementation. Use it for source and issue links. Public contact email remains unset.
